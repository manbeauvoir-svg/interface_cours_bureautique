Activité 1 / 4
Quiz — Affichage & Manipulations
6 questions sur les modes d'affichage, les raccourcis et la différence Copier / Déplacer.
Q1
Quel mode d'affichage de l'Explorateur est le plus adapté pour trier des fichiers par date, type ou taille ?
Réponse : Détails. Ce mode affiche des colonnes personnalisables (nom, date de modification, type, taille) et permet de trier en un clic sur l'en-tête.
Q2
Quel mode d'affichage est idéal pour visualiser rapidement des photos sans les ouvrir ?
Réponse : Icônes (très grandes). Ce mode affiche un aperçu visuel de chaque image, idéal pour parcourir un dossier photo rapidement.
Q3
Quelle est la différence entre Déplacer (Ctrl+X / Ctrl+V) et Copier (Ctrl+C / Ctrl+V) ?
Réponse : Déplacer retire, Copier duplique. Après un Déplacer, le fichier n'existe qu'à la destination. Après un Copier, il existe aux deux endroits.
Q4
Quel mode d'affichage est le plus pratique pour parcourir rapidement un grand nombre de fichiers ?
Réponse : Liste. Ce mode affiche les éléments en colonnes compactes avec de petites icônes, ce qui est pratique pour parcourir beaucoup de fichiers.
Q5
Quelle est la différence entre la touche Suppr et le raccourci Maj + Suppr ?
Réponse : Suppr → Corbeille ; Maj+Suppr → suppression définitive. Attention avec Maj+Suppr : impossible de récupérer le fichier ensuite !
Q6
Quel raccourci clavier permet de renommer un fichier ou dossier dans l'Explorateur ?
Réponse : F2. Sélectionnez l'élément puis appuyez sur F2 : le nom devient éditable. Confirmez avec Entrée.
Activité 2 / 4
Choisir la bonne méthode
Pour chaque situation, sélectionnez la méthode la plus adaptée : Ruban, Clic droit ou Raccourci clavier.
Situation 1
⌨️ Vous tapez un document Word. Sans quitter le clavier, vous voulez créer un nouveau dossier dans l'Explorateur.
Réponse : Raccourci clavier (Ctrl+Shift+N). Idéal pour créer un dossier sans toucher la souris, directement depuis le clavier.
Situation 2
🖱️ Vous êtes dans un dossier vide et vous souhaitez créer un nouveau sous-dossier en explorant les options disponibles.
Réponse : Clic droit dans la zone vide. Le menu contextuel affiche "Nouveau > Dossier". Pratique pour explorer les options disponibles.
Situation 3
📄 Vous avez sélectionné 5 fichiers et vous voulez les déplacer le plus rapidement possible dans un autre dossier.
Réponse : Raccourci clavier (Ctrl+X → Ctrl+V). Couper-coller au clavier est la méthode la plus rapide pour déplacer une sélection.
Situation 4
✏️ Vous voulez renommer un fichier mais vous n'êtes pas sûr du raccourci clavier. Vous préférez utiliser la souris.
Réponse : Clic droit → Renommer. Sans connaître F2, le clic droit reste la méthode la plus accessible à la souris. Le Ruban fonctionne aussi.
Situation 5
🗑️ Vous venez de déplacer un fichier par erreur. Vous voulez annuler immédiatement l'action.
Réponse : Raccourci clavier (Ctrl+Z). Ctrl+Z annule immédiatement la dernière action dans l'Explorateur — la méthode la plus rapide.
Situation 6
🔍 Vous découvrez l'Explorateur et vous voulez changer le mode d'affichage pour passer en vue "Détails".
Réponse : Ruban (onglet Affichage). C'est depuis l'onglet "Affichage" du Ruban que l'on accède à tous les modes d'affichage disponibles.
Activité 3 / 4
Remettre les étapes dans l'ordre
Glissez les étapes pour les remettre dans le bon ordre. Cliquez sur une étape pour la déplacer.
Manipulation 1
Renommer un fichier avec le clavier
🎯 Objectif : renommer "rapport.docx" en "Rapport_Final.docx" avec la touche F2
? Le nom passe en mode édition — le texte existant est surligné
? Appuyer sur Entrée pour valider
? Cliquer une fois sur le fichier rapport.docx pour le sélectionner
? Saisir le nouveau nom : Rapport_Final.docx
? Appuyer sur la touche F2
Manipulation 2
Déplacer un fichier (Couper-Coller)
🎯 Objectif : déplacer "budget.xlsx" du Bureau vers le dossier Documents
? Appuyer sur Ctrl + X pour couper le fichier
? Sélectionner le fichier budget.xlsx sur le Bureau
? Appuyer sur Ctrl + V pour coller dans Documents
? Naviguer vers le dossier Documents dans l'Explorateur
Manipulation 3
Supprimer un fichier et le vérifier dans la Corbeille
🎯 Objectif : supprimer ancien_doc.docx sans le perdre définitivement
? Appuyer sur la touche Suppr — le fichier part dans la Corbeille
? Ouvrir le dossier qui contient ancien_doc.docx
? Cliquer une fois sur ancien_doc.docx
? Ouvrir la Corbeille pour vérifier que le fichier s'y trouve
